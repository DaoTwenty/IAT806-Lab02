# IAT 806 - Lab 02

A p5.js sketch of a ball that bounces off the left/right/top/bottom edges of the canvas, growing and shrinking between a minimum and maximum size as it moves. The ball changes color depending on which half of the canvas it's in.

Click and hold the mouse to apply a repellant force that pushes the ball away from the cursor.

## Run

Open `index.html` in a browser.
